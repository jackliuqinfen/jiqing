# 项目管理可配置视图侧栏设计

日期：2026-07-16
状态：已确认
适用范围：桌面端项目管理模块及后台管理端

## 1. 背景

平台顶部导航已经承担“工作台、招投标、项目管理、资料、结算”等平台级模块切换。当前左侧栏继续放置模块入口、业务动作和系统状态，造成导航职责重复，也占用了能够表达当前工作上下文的空间。

项目管理同时包含项目主档案、生命周期、资料完整度、审计推进和异常处理。左侧栏应从“功能菜单”升级为同一项目数据集的“工作视图目录”，让用户以不同组织方式查看和处理项目，而不是进入多个彼此割裂的子系统。

## 2. 设计目标

1. 顶部导航只负责平台级模块，左侧栏只负责项目管理内部的工作视图。
2. 用户进入项目管理后，优先看到当前需要处理的事项。
3. 项目台账、生命周期、资料和审计视图共享同一套项目主数据。
4. 支持企业公共视图和用户个人视图，同时保持核心导航稳定。
5. 管理员可以调整左栏结构，但不能破坏核心项目管理入口和业务语义。
6. 适合小型工程企业，不建设完全自由的多维表格或无代码数据库。

## 3. 非目标

- 不允许普通用户自由创建核心业务字段或修改生命周期状态机。
- 不允许视图筛选绕过数据权限。
- 不在第一期提供甘特图、自动化编排或任意公式字段。
- 不按岗位生成完全不同的项目管理导航。
- 不在左侧栏放置“上传合同建档、发起审计、上传资料、纳入结算”等业务动作。

## 4. 导航职责

### 4.1 顶部平台导航

```text
工作台 / 招投标 / 项目管理 / 资料 / 结算
```

审计不再作为独立的顶部平台模块。审计是项目生命周期中的专业视图，共用项目主档案、合同、主体、人员、资料和金额事实。

### 4.2 项目管理左侧栏

```text
项目管理

我的工作
  我的工作

项目全景
  生命周期看板
  项目台账

专项视角
  阶段阻塞
  资料缺口
  审计进度

我的视图
  用户保存的个人视图
  + 保存当前视图
```

“我的工作”默认作为项目管理入口。管理员可将企业默认入口改为任一核心视图，用户也可以保存个人默认入口。

### 4.3 页面内导航

页面内不再重复提供与左栏相同的“看板 / 表格 / 审计”等主视图切换。页面顶部只保留：

- 当前视图名称和说明；
- 搜索、筛选、排序和分组；
- 视图级操作；
- “上传合同创建项目”等当前页面主操作。

## 5. 核心视图

以下三个视图为受保护核心视图：

| 固定内部标识 | 默认名称 | 默认形式 | 主要用途 |
| --- | --- | --- | --- |
| `project.my-work` | 我的工作 | 任务列表 | 查看待本人处理、本人负责和本人关注的项目事项 |
| `project.lifecycle` | 生命周期看板 | 看板 | 按工程生命周期阶段查看和推进项目 |
| `project.ledger` | 项目台账 | 表格 | 查询、筛选、批量处理和打开项目主档案 |

保护规则：

- 管理员可以修改显示名称、图标、顺序、分组和默认入口；
- 管理员不能隐藏、删除或更换内部标识；
- 视图配置不能改变生命周期准入规则、核心字段或数据权限；
- 个人用户不能覆盖企业对核心视图的保护规则。

## 6. 默认专项视图

| 固定内部标识 | 默认名称 | 默认形式 | 默认规则 |
| --- | --- | --- | --- |
| `project.blocked` | 阶段阻塞 | 表格 | 当前阶段存在未满足准入条件的项目 |
| `project.document-gaps` | 资料缺口 | 表格 | 当前阶段必需资料存在缺失的项目 |
| `project.audit-progress` | 审计进度 | 看板 | 验收合格后进入送审、一审、二审或政府审计、定案的项目 |

专项视图可以由管理员隐藏、改名、排序或调整默认筛选，但不得改变后端对阻塞、资料缺失和审计阶段的业务判定。

## 7. 视图定义

一个视图由以下配置组成：

```text
viewKey
显示名称
所属分组
展示形式：表格 / 看板 / 任务列表
数据范围：全部可见项目 / 本人负责 / 本人关注
筛选条件
分组方式
排序方式
显示字段
数量提醒规则
访问范围
是否企业默认
是否允许个人复制
```

数量角标只显示具有行动意义的待处理数量，不显示无意义的项目总数。角标计算必须沿用后端统一口径。

## 8. 公共视图与个人视图

### 8.1 公共视图

- 由管理员创建、配置和发布；
- 所有有权访问项目管理的用户看到相同核心骨架；
- 专业视图可以限制访问范围，但不能为每个岗位生成完全不同的导航；
- 公共视图修改采用草稿、预览、发布和回滚流程。

### 8.2 个人视图

用户可以基于有权访问的数据保存：

- 筛选条件；
- 分组和排序；
- 表格列或看板卡片字段；
- 展示形式；
- 个人视图名称；
- 个人默认入口。

个人视图不能新增业务字段、扩大数据范围、覆盖核心视图或修改公共视图。

## 9. 后台配置终端

后台入口：

```text
后台设置 / 项目管理设置 / 左栏与公共视图
```

编辑器采用三栏结构：

1. 左侧：项目管理左栏实时预览；
2. 中间：分组和视图树，支持拖拽排序；
3. 右侧：当前分组或视图的属性配置。

管理员可以：

- 新建、重命名、排序和折叠视图分组；
- 创建企业公共视图；
- 调整公共视图名称、图标、说明和顺序；
- 设置默认入口、默认筛选、分组、排序和显示字段；
- 设置待处理数量角标；
- 设置专业视图访问范围；
- 设置是否允许个人视图及个人视图数量上限；
- 以指定岗位预览发布后的导航和数据范围；
- 查看影响范围、发布配置和回滚历史版本。

## 10. 权限规则

1. 核心视图对所有有项目管理权限的用户可见。
2. 数据范围仍由用户角色、项目成员关系和项目权限决定。
3. 无编辑权限的用户可以查看视图，但不能执行推进阶段、编辑项目或批量操作。
4. 专业视图访问限制只控制入口和可见数据，不改变底层项目事实。
5. 用户同时拥有多个岗位角色时，权限取授权并集，左栏结构保持稳定。

## 11. 交互规则

- 点击左栏视图后更新 URL 中的稳定视图标识，支持刷新、收藏和分享链接。
- 切换视图保留当前项目上下文；从项目详情返回时回到来源视图和原滚动位置。
- 个人修改筛选后显示“保存为个人视图”，不直接覆盖公共视图。
- 公共视图被管理员调整后，已打开页面提示刷新，不强制打断用户当前操作。
- 视图不可用或无权限时回退到“我的工作”，并说明回退原因。
- 无真实数据时展示诚实空状态，不生成示例项目。

## 12. 页面动作归属

以下动作不进入左栏：

| 动作 | 归属位置 |
| --- | --- |
| 上传合同创建项目 | 项目管理页面右上角主按钮 |
| 发起或推进审计 | 项目详情当前阶段动作 |
| 上传资料 | 项目详情资料区或资料模块 |
| 纳入结算管理 | 项目详情或结算模块 |
| 批量操作 | 项目台账选中记录后的工具栏 |

## 13. 第一阶段范围

第一阶段只实现：

1. 三个受保护核心视图；
2. 阶段阻塞、资料缺口和审计进度三个系统专项视图；
3. 公共视图排序、改名、默认入口和显示控制；
4. 用户保存个人筛选视图；
5. 左栏视图与 URL 状态同步；
6. 管理端预览、发布和回滚。

暂不实现甘特图、自由字段、公式、跨表关联和自动化工作流。

## 14. 验收标准

1. 顶部导航与左栏不存在重复的平台模块入口。
2. 项目管理默认进入“我的工作”，或按已发布配置进入其他核心视图。
3. 三个核心视图无法在后台被隐藏或删除。
4. 左栏不再出现上传、发起、系统状态和显示方式等非视图内容。
5. 审计进度作为项目管理视图读取统一项目数据，不重复创建项目。
6. 用户可以保存个人视图，但不能看到权限范围之外的项目。
7. 管理员可以预览、发布和回滚项目管理左栏配置。
8. 公共视图链接可刷新、收藏和分享，并恢复相同视图状态。
9. 没有数据时只显示空状态，不出现模拟业务记录。
